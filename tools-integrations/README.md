# Tools Integrations

This directory contains source snapshots for local MCP integrations used by the Codex local client.

- `codesys-codex-mcp`: CODESYS project read/export/import/build MCP server and helper scripts.
- `autocad-codex-mcp`: AutoCAD drawing MCP server and helper scripts.

The snapshots intentionally exclude local credentials, `.git` directories, `node_modules`, runtime caches, and generated package output. Reinstall dependencies in each integration directory when needed.
